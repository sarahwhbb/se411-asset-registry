# SE411 Computer Asset Registry

SE411 (Fall 2026-27) team project: a web app for managing a company's computers (add, view, edit, delete).

- **Part 1:** React frontend (`frontend/`).
- **Part 2:** Spring Boot REST API with an H2 database (`backend/`), integrated with the frontend.

## Features

- Home page with asset counts by status
- Menu on every page: Home, Computers, Add Computer, About
- List all computers with status badges
- Add and edit computers with form validation (required fields, unique asset tag, no future purchase date, price above 0)
- Delete with confirmation
- About page with the team members
- Responsive layout (table on wide screens, cards on narrow ones)

## Tech stack

- **Frontend:** React 19, Vite, React Router, Vitest + React Testing Library, oxlint.
- **Backend:** Java 21, Spring Boot 4, Spring Web, Spring Data JPA, H2 (in-memory), Maven, JUnit + Mockito.

## Getting started

Requires Node.js 22.12 or later (Node 24 LTS recommended), npm, JDK 21 or later and Maven.

Start the backend first, then the frontend (two terminals):

```bash
git clone https://github.com/sarahwhbb/se411-asset-registry.git
cd se411-asset-registry

# Terminal 1: backend at http://localhost:8080
cd backend
mvn spring-boot:run

# Terminal 2: frontend at http://localhost:5173
cd frontend
npm install
npm run dev
```

The database is in-memory H2, so data is lost when the backend stops. The list starts empty; add computers from the app.

Other scripts:

```bash
npm test         # frontend tests (in frontend/)
npm run lint     # lint the frontend
npm run build    # production build into frontend/dist/
mvn test         # backend tests (in backend/)
```

## REST API

Base URL `http://localhost:8080/api/assets` (CORS allows `http://localhost:5173`).

| Method | Route | Purpose |
|---|---|---|
| POST | `/api/assets` | add a computer (201) |
| GET | `/api/assets/{id}` | find by id (404 if missing) |
| GET | `/api/assets?page=&size=` | paginated list (Spring `Page`, defaults page 0, size 10) |
| PUT | `/api/assets/{id}` | update (404 if missing) |
| DELETE | `/api/assets/{id}` | delete (204, 404 if missing) |

## Computer fields

`id` (generated by the backend), `assetTag`, `brand`, `model`, `serialNumber`, `purchaseDate`, `status` (In use / In stock / Repair / Retired), `assignedTo`, `price` (SAR).

## Project structure

```
frontend/src/
├── data/         status list
├── context/      AssetContext (REST calls to the backend: load, add, update, delete)
├── components/   NavBar, Footer
├── pages/        Home, AssetList, AssetForm (add and edit), About
├── utils/        form validation
└── test/         Vitest tests

backend/src/main/java/edu/psu/se411/backend/
├── Asset                  JPA entity
├── AssetRepository        Spring Data JPA repository
├── AssetService           business logic (throws AssetNotFoundException)
├── AssetNotFoundException maps to HTTP 404
└── AssetController        REST controller
```
